# Unity Character Controller

A modular character controller prototype built from scratch in Unity, focusing on clean architecture, input handling, and robust collision mechanics.

## 🛠️ Features
- **Engine:** Unity 6.3 LTS
- **Architecture:** Moving from monolithic prototype to SOLID principles

## 🎨 Credits & Assets
